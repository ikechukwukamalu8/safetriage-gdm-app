# Synthetic SafeTriage-GDM datasets

These files are synthetic and are provided only for testing schema mapping, external validation, fairness auditing, and BMI population-stability monitoring. They are not clinical data and should not be interpreted as clinical truth.

The model predictors are: `maternal_age`, `prepreg_bmi`, `parity`, and `mms_started_by_28_weeks`, with `gdm_status` as the optional target.
